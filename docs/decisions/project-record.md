# Curated project record

This document summarizes the project conversation. It is not a verbatim transcript.
The repository preserves supplied source artifacts separately. This record excludes internal agent instructions and private runtime data.

## Original need

Adham works as a solo designer with about 20 hours each week.
He asked for a practical sequence across product design, UX, UI, design systems, graphics, and implementation review.
The original sources were the SIS documentation repository, Figma workspace, and Jira KAN-16.

The first response proposed a design process and a first-week plan.
Adham then requested guided foundation sessions and chose foundations before screen production.
He removed Shehab, Yasser, and Rouby from design approval requirements.
This change concerns his design work. It does not redefine engineering ownership or university policy.

## Foundation choices

Adham selected a formal, friendly, practical direction.
He requested defined type sizes and weights, rounded corners, a two-pixel spacing base, accessible colors, and deliberate navigation structure.
He selected E-JUST red `#EA232B` as the reference color.
He requested semantic naming that makes light and dark themes interchangeable.
He first kept several fonts and languages available for comparison.
He later chose IBM Plex only, with Arabic RTL and English LTR.
He approved all existing type roles and weights.
He required international digits in Arabic interfaces.

## Workbench choices

Adham requested a complete foundation layer, rather than a prototype that only demonstrates SIS screens.
He requested separate pages for colors, spacing, typography, layers, components, badges, and related examples.
The approved plan selected a searchable sidebar, four navigation groups, and six internal page tabs.
The plan required local functional demonstrations, states, token references, usage guidance, exports, and accessibility checks.
The workbench remains separate from the Advisor frontend and backend.

## Consolidation choices

Adham requested a private GitHub repository containing project work, decisions, reports, prototypes, and rules.
He also requested Jira epics and stories with evidence-based statuses.
He requested suggestions for presentations, documentation, and other future output formats.
Those new templates remain backlog work after the current consolidation.

The final instruction requested complete scale guidance and a richer motion system immediately.
The implementation adds exact easing curves, deterministic spring profiles, motion recipes, and reduced-motion behavior.
The exact new numerical profiles are implementation defaults under this instruction.
