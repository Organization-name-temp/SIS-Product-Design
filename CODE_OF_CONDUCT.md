# Code of conduct

## Our standard

Everyone contributing to this repository acts with professional courtesy. We
critique work, not people. We keep discussions about the design system on
topic and evidence-based.

## The rules

1. Be respectful in issues, pull requests, and reviews.
2. Accept feedback on the work; reject harassment of any kind.
3. Do not publish other people's private information.
4. Respect the design owner's decisions; debate them through the contribution
   process, not through side channels.

## Enforcement

The design owner, Adham Haitham Eid, enforces this code. Report violations
through a private message to the repository owner. Repeated or severe
violations lead to a ban from the repository.
