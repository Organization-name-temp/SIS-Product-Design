# SIS Foundations

A personal interactive design-system workbench for Adham.
Platform: responsive web. Mode: Operate and Read.
The workbench demonstrates reusable foundations and components. It is not a production SIS or component package.
Adham is the sole design approver. Design values remain read-only in the interface.
E-JUST reference red is #EA232B. Light and dark themes share semantic role names.
Use IBM Plex Sans Arabic by default. IBM Plex Sans Arabic is the only active family.
Arabic and English use international digits 0–9. Arabic has genuine RTL layout.
Keep the approved tokens authoritative. Generated visual references guide layout, not replacement color values.
