# Visual contract

Use the supplied foundation contract and exported tokens.
The colors landing page follows public/reference/colors-workbench.png for sidebar, content tabs, palette, and inspector structure.
Exact source token values override approximate swatch values in the generated reference image.
Use formal, friendly, practical typography and neutral surfaces, with meaningful E-JUST red accents.
Do not generate university crests or replace Lucide icons with text glyphs.
Comfortable controls are 48px high. Compact controls retain 44px interactive targets.
Use 14px minimum standard interface text. Body text is 16px.
RTL, light/dark, IBM Plex, density, and preview width remain independent.
